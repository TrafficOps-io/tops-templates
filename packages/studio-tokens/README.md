# @trafficops/studio-tokens

Семантический слой дизайн-токенов студий TrafficOps: переменные `--ui-*` на корне `.studio-root` (`tokens.css`) и две темы, `studio-light` и `studio-dark` (`themes.css`). Значения те же, что в `tokens.json`, который используют тесты контраста и синхронизации.

Подключение: Tailwind 4 и daisyUI 5 обрабатывают `themes.css` (директива `@plugin "daisyui/theme"`); `tokens.css` — обычный CSS, его можно импортировать без сборщика тем. Хост без тем задаёт `--color-*` сам, как PWApps через класс `.dark`.

Правило: в продуктовом коде используются только `--ui-*`; цветовые и размерные литералы вне пакета ловит тест.
