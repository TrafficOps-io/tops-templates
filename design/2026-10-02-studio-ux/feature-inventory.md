## Функциональные invariants и source anchors

1. Capability boundary: `editor/src/app-mode.js`, `App.jsx:29,43,398`, `hosts/StudioAiPort.js`, `hosts/StudioHost.js:29`, tests `production-flows.test.js`, `pwa-ports.test.js`. `?studio=1`, fullscreen in ordinary browser and `appinstalled` event alone do not grant AI/fs. confirmed standalone/minimal-ui/window-controls-overlay or iOS navigator.standalone establish app session. Real ports recheck gates after async await.
2. Storage/data identity: `studio-library.js`, `directory-projects.js`, `portable-project.js`, `project-transfer.js`, `App.jsx:215-377`. Clone/Use template = independent project identity. Continue import = same identity/history, ZIP continuation selects device save location; folder binding removed to avoid two writable owners. Directory transfer must compare fresh disk/device revisions and preserve conversations.
3. Navigation durability: `App.jsx:178-213`, `useEditorProject.js:56-113`. Flush dirty edits before switching/library/update; autosave650ms; repeated storage failures pause retries until edit/explicit save; errors do not discard in-memory state. Saving may finish while more edits are buffered. Ctrl/Cmd+S supported.
4. AI draft safety: `useEditorProject.js:119-189`, `chat-port.js:195-243`, `conversation-changes.js`, `block-edit-scope.js`. Draft preview never writes source; apply validated only, exactly-once applied-run identity; stale overlapping/current-read changes must gate. A block selection remains frozen, newer preview click cannot broaden scope. Keep invalid interrupted draft distinct from Apply.
5. Runs/history persistence: `conversation-runtime.js`, `editor/src/studio-conversations.js`, `studio-ai-recovery.js`. Background runs may continue when another project opens; library must reflect activity; no automatic paid restart after restore. Delete explicitly stops its runs and removes only device history, leaves folder files. Source export optional conversation history; API keys excluded.
6. Preview isolation/resource lifetime: `PreviewPanel.jsx:12-84`, `useEditorProject.js:219+`, `editor/src/preview/interactive-preview.js`. Retain last ready frame until successor has proved ready; dispose replaced blobs; reject forged/wrong-frame selection messages; never grant iframe same-origin/top-navigation/native capabilities.
7. Host portability: `EditorShell.jsx:38-384`, `HostedEditor.jsx`, `hosts/{LibraryHost,StudioHost}.js`. Browser/PWA main editor presentation=app, shared exported compact/expanded embedded editor separate. Locale/versions/external preview only capability declared by embedding host; local Studio exposes none. New CSS should be scoped for app layout where changes differ.
8. Languages/themes: `theme.js`, `ThemeToggle.jsx`, `packages/studio-ui/src/i18n`, `studio-i18n.js`, `LocaleMenu.jsx`. System/light/dark persisted under studio-theme; native theme-color follows toolbar surface. Standalone UI language default en via host; locales feature is template-content language in supported external hosts, not a global UI-language picker.
9. Keyboard/AT/touch: existing Menu/Tabs/Modal/ConfirmDialog/ResizableWorkspace preserve focus-return, arrows/Home/End/Esc, outside dismiss, resizer keyboard. Touch targets>=44, desktop dense targets>=32, no mobile hover-only action hiding. Brand logos are meaningful navigation marks; decorative inline glyphs can remain aria-hidden.

## Точечные gaps, обнаруженные во время функционального аудита

- Narrow chat switches to `ChatHeader` menu containing open threads only while hides full ThreadList. Search/archive/restore/delete controls exist in source but inaccessible through that compact header. This is functional access gap to assess, not proposal to remove management.
- Locale/Versions references in design/screens must distinguish template content locale and published host versions from conversations branches; these are different concepts.
- Conflicts can produce outer app error, toolbar error and hosted callout simultaneously. These surfaces have distinct recovery actions (reload/copy/export) and cannot simply be CSS-hidden globally.
- Browser library has multiple creation paths pointing to same dialog/mode; any consolidation must preserve direct template/blank entry and selected-source handoff.
- Project storage mode is currently honest device-vs-folder with clear recovery path. Future folder-first spec should not be represented as current behavior during UI cleanup.
